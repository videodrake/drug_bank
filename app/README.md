# 💊 약물 학습기 (Drug Study App)

다빈도 처방 약물(Top 200/300)을 **근거 기반 학습법**으로 익히는 웹앱.
설치 없이 `index.html`을 브라우저로 열면 바로 동작합니다. (바닐라 HTML/CSS/JS, 외부 의존성 없음)

## 실행
```
app/index.html  ← 더블클릭 또는 브라우저로 열기
```
학습 진행은 브라우저 **localStorage**에 자동 저장됩니다.

## 구현된 학습법
| 모듈 | 학습법 | 설명 |
|---|---|---|
| **계열 학습** | 청킹 + 프로토타입 | 약을 계열·MOA로 묶고, 대표약(프로토타입) 중심으로 학습 |
| **복습** | 간격반복(SM-2) + 인출연습 | 답을 먼저 떠올린 뒤 카드를 뒤집고 난이도 평가 → 망각곡선에 맞춰 다음 복습일 자동 배치 |
| **어간 사전** | 내장 니모닉 | 어간 30개로 계열 추론 |
| **인터리빙 퀴즈** | 변별력 강화 | 여러 계열을 섞어 출제 |
| **대시보드** | 진행 추적 | 학습/복습대기/미학습 통계 + 카테고리별 진행률 |

## 구조
```
app/
├─ index.html          앱 셸 + 탭 네비게이션
├─ css/style.css       다크 테마 UI
├─ js/
│  ├─ srs.js           간격반복 엔진(SM-2) + localStorage
│  └─ app.js           뷰 렌더링·플래시카드·퀴즈 로직
└─ data/
   ├─ drugs.js         약물 데이터 (계열별 추가)
   └─ stems.js         어간 사전 (30개)
```

## 약물 데이터 추가 방법
`data/drugs.js`의 `DRUGS` 배열에 객체를 추가하면 모든 모듈에 자동 반영됩니다.
```js
{ id:'고유키', generic:'성분명(한글)', genericEn:'Generic', brand:'상품명',
  category:'대분류', klass:'계열', stem:'-어간', isPrototype:true /*대표약*/,
  moa:'작용기전', indication:'적응증', sideEffects:'부작용',
  contraindication:'금기', dose:'용법용량', note:'비고(선택)' }
```

## 현재 수록 현황
- **82종** / 8개 카테고리 (심혈관계, 소화기·대사, 항감염, 신경·정신계, 진통·소염·근골격, 호흡기·알레르기, 비뇨·생식, 골·기타)
- 58개 계열 · 어간 30종
- 계열별로 계속 확장 중 (목표 Top 300)

> 학습 콘텐츠는 교육용입니다. 실제 처방·복약 지도는 최신 허가사항과 가이드라인을 확인하세요.
