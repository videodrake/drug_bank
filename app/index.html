오늘의 학습

간격반복 큐에서 복습할 약물과 진행 현황입니다.

학습법 적용 현황

  • 계열 청킹 · 약을 계열·기전(MOA)으로 묶고 프로토타입 약물 중심으로 학습
  • 간격반복 · 복습 큐가 망각곡선에 맞춰 오늘 볼 카드를 자동 배치
  • 인출연습 · 카드를 뒤집기 전 먼저 답을 떠올리고 난이도를 평가
  • 어간 학습 · 약물명 어간으로 계열을 추론
  • 인터리빙 · 여러 계열을 섞어 변별력 강화 퀴즈

카테고리별 진행률

계열 학습 청킹 + 프로토타입

계열별로 대표약(프로토타입)을 먼저 익히고, 나머지는 차이점만 학습하세요.

복습 간격반복 + 인출연습

먼저 답을 떠올린 뒤 카드를 뒤집고, 얼마나 잘 기억했는지 평가하세요.

어간 사전 내장 니모닉

어간 ~30개만 외우면 수백 개 약의 계열을 추론할 수 있습니다.

인터리빙 퀴즈 변별력 강화

여러 계열을 섞어 출제합니다. 헷갈리는 계열을 구분하는 힘을 기릅니다.
